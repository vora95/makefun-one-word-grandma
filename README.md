A small program that writes exactly one word (10 characters) to `/output/entry.txt`: the single word the entrant's grandma would text about AI — "Witchcraft". No sentence, no explanation, no punctuation tricks: the oldest word she has for a machine that should not be able to talk.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

No network, no model calls, deterministic output.
